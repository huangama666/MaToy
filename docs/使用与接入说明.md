# MaToy 使用与接入说明

固件版本：2026-11-07。项目名称：MaToy。说明更新：2026-11-09。适用于本项目的 ESP32-C3、8 MB Flash、240×320 屏幕 AI Passport。Mac 应用为 Apple 芯片 arm64 版本，本次在 macOS 26 环境构建、验证。

项目及后续构建名称统一为 MaToy。当前随附预编译应用仍名为「AI Passport 实时控制.app」，固件也保留原发布文件名；使用随附文件时按本文命令操作。自行构建后的应用为 `outputs/MaToy.app`，macOS 权限列表名称为「MaToy」。

## 现在怎样使用

随附镜像是此前已刷入的音视频版本；本次只整理项目文件，未重新刷机或复测设备在线状态。本机原 Wi-Fi 和配对配置继续保留。开机先显示小狗插画，再进入纯色竖屏首页，三个入口依次为「电台」「远程桌面」「远程监控」。上下键选择，确定键进入。游戏已被应用固件替换，不再作为开机入口。

### 远程监控：看摄像头、听声音、语音对讲

打开 Mac 上的「AI Passport 实时控制.app」，再在开发板进入「远程监控」。每次重新进入时默认开启 Mac 摄像头，声音默认关闭。画面和按钮采用竖屏布局。

上下键在以下六个按钮间移动，短按确定执行：

| 按钮 | 作用 |
| --- | --- |
| 开启镜头 | 打开 Mac 摄像头并接收画面 |
| 关闭镜头 | 停止摄像头采集并清空开发板预览 |
| 开启声音 | 听 Mac 麦克风采集的环境声音 |
| 关闭声音 | 停止监控音频采集和传输 |
| 语音对讲 | 听 Mac，并允许开发板向 Mac 讲话 |
| 返回首页 | 离开监控，释放摄像头和监控音频会话 |

在「语音对讲」模式，**按住开发板下键讲话，松手恢复听 Mac**。这是按键式轮流对讲。短按下键仍用于移动菜单选中项。长按确定也可返回首页。摄像头和声音可分别关闭；关闭镜头不会自动关闭已经开启的声音。离开监控或连接断开，会结束该监控会话的采集。

这里的「开启声音」监听的是 **Mac 麦克风**；远程桌面模式里的「传送 Mac 系统声音」是另一项来源选择。

### 远程桌面

进入后使用横屏，显示当前 Mac 会话。放大只裁剪、缩放发送给开发板的图像，不改变 Mac 桌面的缩放设置。6 倍文字模式、3 倍跟随模式可从 Mac 的 Passport 菜单选择。

| 操作 | 功能 |
| --- | --- |
| 确定键快速按三下 | 全桌面与原放大视图切换 |
| 确定键快速按两下 | 打开或关闭屏幕键盘 |
| 鼠标模式短按上下键 | 沿当前方向移动鼠标 |
| 鼠标模式短按确定 | 单击 |
| 鼠标模式长按确定 | 切换横向、纵向移动 |
| 鼠标模式长按上键 | 打开右上角分类菜单 |
| 菜单内上下键、短按确定、长按确定 | 选择、进入或执行、返回 |
| 鼠标模式按住下键 | 向 Mac 讲话，松开继续听 |
| 键盘模式短按上下键、长按上下键 | 选字符、切字符组 |
| 键盘模式短按确定、长按确定 | 输入、退格 |

键盘含字母、数字和特殊键组；Enter 在特殊键组中。右上角菜单分显示、控制、声音和系统；从系统分类返回首页或进入待机。待机使用小狗插画。Mac 本身锁屏时仍遵循 macOS 的锁屏规则，本工具不绕过登录保护。

### 电台

竖屏播放网络广播，无需启动 Mac 发送端，但需要开发板连接 Wi-Fi。当前目录有 345 个频道、31 个地区；公开广播源可能变化，目录数量不代表每条流始终在线。

短按上下键切台，短按确定暂停或继续；长按上键加音量、长按下键减音量，每次 5，范围 0～90。长按确定打开选台菜单，其中也有独立的「音量」入口；双按确定返回首页。

## 项目目录与本机配置

```text
MaToy/
  source/firmware/              当前正式固件 C 源码与 BSP
  source/mac/                   当前 Mac 发送端 Swift 源码
  source/wifi-setup/            临时 USB 配网固件源码
  firmware/                     正式镜像、临时配网镜像及校验清单
  scripts/                      两端构建脚本
  tools/接入.py                  USB 配置和配对
  assets/                       资源生成所需字体
  outputs/AI Passport 实时控制.app
  work/mac-screen-pair.json     本机配对密钥，不能分享
  docs/                         使用、开发与刷入说明
  第三方许可/
```

本机配对文件已保留在原位置，正在使用的 Mac 应用也保留原路径。日常继续打开 `outputs/AI Passport 实时控制.app` 即可。分享项目时必须排除 `work/mac-screen-pair.json`；换电脑应重新配对。同一台 Mac 若使用复制出的项目目录，只在本机复制配对文件到对应的 `work` 中。运行新副本前先退出旧的 Passport 发送端，避免端口冲突。

## 首次接入或换网络、换电脑

准备 USB 数据线。开发板连接 2.4 GHz Wi-Fi，Mac 和开发板处于能够互通的局域网。桌面、桌面语音、监控画面、监控音频分别使用 TCP 45902、45903、45904、45905。首次安装工具需要 Python 3.10 以上及联网安装依赖。

终端切换到本项目根目录后执行：

```zsh
python3 -m venv .venv
PY="$PWD/.venv/bin/python"
"$PY" -m pip install -r tools/requirements.txt
"$PY" tools/接入.py port
```

关闭占用串口的工具。以下命令在同一个终端、项目根目录中执行。

### 1. 配置 Wi-Fi（网络未变时跳过）

本项目设备的应用分区在 `0x10000`。先刷临时配置应用：

```zsh
PORT=$("$PY" tools/接入.py port) && test -n "$PORT" &&
  "$PY" -m esptool --chip esp32c3 --port "$PORT" --baud 460800 \
  --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x10000 firmware/AI-Passport-WiFi-Setup-app.bin
"$PY" tools/接入.py wifi
```

按提示输入 Mac 的局域网 IPv4、Wi-Fi 名称和密码；IPv4 提示可直接回车采用检测值，不能把密码填在地址栏。密码不回显。看到「Wi-Fi 已写入」后刷正式固件。

### 2. 刷正式应用（已刷本版时跳过）

```zsh
PORT=$("$PY" tools/接入.py port) && test -n "$PORT" &&
  "$PY" -m esptool --chip esp32c3 --port "$PORT" --baud 460800 \
  --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x10000 firmware/AI-Passport-Monitor-Talk-app.bin
```

此命令只写应用分区，保留本项目 NVS 中的 Wi-Fi 和配对。包内 `full.bin` 是从 `0x0` 写入的完整布局镜像，供初始化或恢复布局使用；不要拿它当日常升级命令，对其他分区布局也不要直接套用本节地址。

### 3. 配对（原电脑和地址未变时可复用原配对文件）

```zsh
"$PY" tools/接入.py pair
open "outputs/AI Passport 实时控制.app"
```

工具把 Mac 地址和随机密钥写入板上，并在包内 `work/mac-screen-pair.json` 保存对应配置。看到「USB 配对成功」后等待开发板重启。日常画面、操作和音频走局域网，USB 用于刷机和首次配置。

## Mac 权限与排查

「系统设置 → 隐私与安全性」中，为该应用允许：屏幕与系统音频录制（桌面）、辅助功能（鼠标键盘）、摄像头（监控）、麦克风（环境声音和对讲）。如系统询问本地网络，也需允许。按 macOS 提示退出并重新打开。摄像头和麦克风权限不等于屏幕录制权限。

- 桌面没画面：确认当前应用仍在运行、屏幕录制已开启；应用更新后若旧授权失效，先退出应用，执行 `tccutil reset ScreenCapture local.ai-passport.live-control`，再打开当前副本，重新授权并重开。该命令只处理此应用的屏幕录制记录。
- 摄像头或声音没开：看开发板顶部状态提示；确认相应系统权限和麦克风没有静音，再执行对应开启按钮。
- 只有一个方向有声音：监听模式只提供 Mac → 板；先选「语音对讲」，再按住下键说话。避免两端距离太近产生声学回授。
- 无法控制鼠标：检查辅助功能权限。
- 切换网络后不连接：确认 Mac 当前 IPv4，并通过 USB 重新配对；Wi-Fi 本身变化则重做网络配置。
- 没有串口：使用能传数据的线、让板子开机，并关闭其他串口工具。
